# 小数のわり算

5年生の「小数 ÷ 小数」を、スモールステップで確認しながら練習する算数教材です。
「小数のかけ算」（shosu-kakezan）と同じ作りで、見当 → 筆算 → 小数点の位置の確認、の順に進めます。

公開ページ： https://tt-sensei.github.io/shosu-warizan/ （予定）

## 学習の流れ（1問の進み方）

1. **見当**：計算の前に、「答えがもとの数（わられる数）より大きくなるか、小さくなるか」を選ぶ。わる数が1より小さいかどうかがポイント。見当違いも、つまずいた段階として記録する。
2. **筆算**：
   - じゅんび：小数 ÷ 小数では、わられる数とわる数を同じく10倍・100倍して、わる数を整数に直す（何倍するかは子どもが選ぶ）。
   - わり算の筆算を、商を立てる位ごとに1桁ずつ入力して進める。商が大きすぎて引けない場合、小さすぎてあまりがわる数以上になる場合は、その場で短く声をかける。
3. **小数点の位置の確認（独立したステップ）**：
   - 筆算で出た商の数字の列に、タップで小数点を打つ。正しい位置は「ずらした後のわられる数の小数点の真上」。
   - 間違えた位置に打つと、その位置だと答えがいくつになってしまうかと、見当（大きくなる／小さくなる）を示して考え直させる。
   - 答えが整数になる問題では、小数点が要らないことを確認する。
   - 打ったあと、「なぜその位置になるか」を、その問題の数で短く示す。
4. 正解・不正解のフィードバックはその場で出る。途中でつまずいた段階（見当／筆算／小数点の位置）を問題ごとに記録する。

間違えた問題は「とっくん」に記録され、手順ノーミスで正解すると記録から外れます（克服）。とっくんに敵・HP・タイマーはありません。

## 問題の種類（各10問・自動生成）

| 種類 | 内容 | 案内役 |
| --- | --- | --- |
| ふくしゅう：小数 ÷ 整数 | 小数第1位・第2位 ÷ 1桁の整数（4年生の復習） | りく |
| 小数 ÷ 小数（わる数 第1位） | 3.6 ÷ 1.2 のような基本の小数 ÷ 小数 | つき |
| 小数 ÷ 小数（わる数 第2位） | 7.2 ÷ 0.24、0.75 ÷ 0.25 など | かい |
| ミックス チャレンジ | 上記の混合 | さく |

「小数 ÷ 小数（第1位）」「小数 ÷ 小数（第2位）」「ミックス」の10問には、**わる数が1より小さい型（答えがもとの数より大きくなる）**が必ず2問入ります。

問題は、商とわる数を先に決めてわられる数を逆算して作るので、必ず割り切れます（無限小数は出しません）。商を立てる回数は5回までに抑え、解く画面がタブレット1画面（1180×820）にスクロールなしで収まるようにしています。問題は練習のたびに自動生成されます（同じ回の10問の中で同じ式は出しません）。

## 保存（この端末のブラウザー内のみ）

- `shosuWarizan.mistakes.v1`：間違えた問題と、つまずいた段階（estimate／hissan／point）
- `shosuWarizan.stats.v1`：種類ごとの実施数と手順ノーミス数
- `shosuWarizan.settings.v1`：音のON/OFF

## 技術・利用

- HTML / CSS / JavaScriptで動作する静的な教材です。外部API・外部CDN・外部フォントは使いません。
- 音は sounds-recipe-、演出のCSSは edu-effects、キャラクター画像は navi-character の自前共通基盤を利用します（読み込めなくても学習は続けられます）。
- 学習記録は利用端末のブラウザー内に保存します。サーバー側データベースは使用しません。

## 仮置きした判断（2026-11-26 制作時）

- アプリ名は「小数のわり算」（仮称）。リポジトリ名は `shosu-warizan` とする想定。
- テーマ色は青系（#1b7fbd）。「小数のかけ算」の紫と重ならないようにした。
- 見当の間違いも「つまずいた段階」として記録する（かけ算版では見当は記録しないが、本アプリの仕様指定にしたがった）。
