# 小数のわり算

5年生の「小数 ÷ 小数」を、スモールステップで確認しながら練習する算数教材です。
「小数のかけ算」（shosu-kakezan）と同じ作りで、見当 → 筆算 → 小数点の位置の確認、の順に進めます。復習コース（小数 ÷ 整数）では、わる数が必ず1より大きくなるため、同じ答えになりやすい大小の見当問題を省略します。

公開ページ： https://tt-sensei.github.io/shosu-warizan/

## 学習の流れ（1問の進み方）

1. **見当**：小数 ÷ 小数では、計算の前に「答えがもとの数（わられる数）より大きくなるか、小さくなるか」を選ぶ。わる数が1より小さいかどうかがポイント。見当違いも、つまずいた段階として記録する。小数 ÷ 整数の復習では、この問いを省略する。
2. **筆算**：
   - じゅんび：小数 ÷ 小数では、わられる数とわる数を同じく10倍・100倍して、わる数を整数に直す（何倍するかは子どもが選ぶ）。
   - わり算の筆算を、商を立てる位ごとに1桁ずつ入力して進める。商が大きすぎて引けない場合、小さすぎてあまりがわる数以上になる場合は、その場で短く声をかける。
3. **小数点の位置の確認（独立したステップ）**：
   - 画面上段に「ずらした後のわられる数」、下段に「商の数字」を位をそろえて表示する。上の小数点と同じ位置に、下段のタップで小数点を打つ。わられる数が整数の場合は、一の位の右を小数点の位置として示す。
   - 間違えた位置に打つと、その位置だと答えがいくつになってしまうかと、見当（大きくなる／小さくなる）を示して考え直させる。
   - 答えが整数になる問題では、小数点が要らないことを確認する。
   - 打ったあと、「なぜその位置になるか」を、その問題の数で短く示す。
4. 正解・不正解のフィードバックはその場で出る。途中でつまずいた段階（見当／整数に直す／筆算／小数点の位置）を問題ごとに記録する。

間違えた問題は「とっくん」に記録され、手順ノーミスで正解すると記録から外れます（克服）。とっくんに敵・HP・タイマーはありません。

## 個別最適化

- 見当／整数に直す／筆算／小数点の4段階を別々に記録します。
- 通常練習と「今日のおすすめ」での初回の取り組みを記録し、「とっくん」のやり直し結果は初回正答率に混ぜません。
- 各段階の直近最大10回の取り組みを保存し、推薦は通算成績ではなく最近の様子を中心に判断します。
- 直近5回以上の記録があり、2回以上つまずき、つまずき率が40%以上の段階は、その段階を中心にしたおすすめ10問を作ります。
- 重点練習では、見当（わる数が1より小さい／大きい問題を半分ずつ）、整数に直す（10倍／100倍を半分ずつ）、筆算（商を立てる回数を抑えた問題）、小数点（小数の商を中心にした問題）を出します。
- 4段階すべてで直近10回の記録がそろい、つまずき率が15%以下の場合は、発展問題をおすすめします。
- 小数点の技能は、実際に小数点の位置を選ぶ必要がある「小数の商」の問題だけを評価します。答えが整数になる問題は、この技能の成功・失敗に数えません。
- データが少ない間はミックス問題をおすすめし、理解度を早く決めつけません。
- 直近記録はこの仕上げ以降の取り組みから集めます。これまでの通算記録は保持しますが、以前の結果を直近の様子として扱わず、新しい記録がたまってから推薦に反映します。

## 問題の種類（各10問・自動生成）

| 種類 | 内容 | 案内役 |
| --- | --- | --- |
| ふくしゅう：小数 ÷ 整数 | 小数第1位・第2位 ÷ 1桁の整数（4年生の復習） | りく |
| 小数 ÷ 小数（わる数 第1位） | 3.6 ÷ 1.2 のような基本の小数 ÷ 小数 | つき |
| 小数 ÷ 小数（わる数 第2位） | 7.2 ÷ 0.24、0.75 ÷ 0.25 など | かい |
| ミックス チャレンジ | 上記の混合 | さく |

「小数 ÷ 小数（第1位）」「小数 ÷ 小数（第2位）」「ミックス」の10問には、**わる数が1より小さい型（答えがもとの数より大きくなる）**が必ず2問入ります。

問題は、商とわる数を先に決めてわられる数を逆算して作るので、必ず割り切れます（無限小数は出しません）。商を立てる回数は5回までに抑え、解く画面がタブレット1画面（1180×820）にスクロールなしで収まるようにしています。問題は練習のたびに自動生成されます（同じ回の10問の中で同じ式は出しません）。

## 保存（この端末のブラウザー内のみ）

- 学習記録は1人目〜6人目の6枠に分けて保存できる。名前やアカウント登録は不要。これは記録を整理するための切替で、本人確認やパスワードによる保護ではない。
- `shosuWarizan.skillProfile.v1.learner-N`：学習者ごとの4段階の練習機会・初回成功数・つまずき数
- `shosuWarizan.mistakes.v1.learner-N`：学習者ごとの間違えた問題と、つまずいた段階（estimate／shift／hissan／point）
- `shosuWarizan.stats.v1.learner-N`：学習者ごとの種類別実施数と手順ノーミス数
- `shosuWarizan.settings.v1`：音のON/OFF（端末共通）
- 既存の学習記録は初回起動時に1人目へ引き継ぐ。記録はブラウザー内に保存され、別の端末やブラウザーとは共有されない。

## 技術・利用

- HTML / CSS / JavaScriptで動作する静的な教材です。外部API・外部CDN・外部フォントは使いません。
- 音は sounds-recipe-、演出のCSSは edu-effects、キャラクター画像は navi-character の自前共通基盤を利用します（読み込めなくても学習は続けられます）。
- 学習記録は利用端末のブラウザー内に保存します。サーバー側データベースは使用しません。共有端末では、トップ画面で学習記録を使う人（1人目〜6人目）を切り替えて利用できます。
- 記録画面から、選択中の学習者の「間違い直し・種類別成績・技能記録」をJSONファイルに保存し、別の端末やブラウザーへ移せます。読み込み先で学習者を選択してから読み込むと、その人の記録を置き換えます。音の設定はバックアップ対象に含みません。

## 設計上の補足

- テーマ色は青系（#1b7fbd）。「小数のかけ算」の紫と区別している。
- 小数 ÷ 整数の復習では、わる数が1より大きい問題だけになるため、大小の見当を省略する。
